# RIP Lab @ JejuNU — Official Website

Rare & Invisible Physics Laboratory (RIP Lab), Department of Physics, Jeju National University.

## How to Deploy on GitHub Pages
1. Create a new public repository named `<your-github-username>.github.io` (or any repository name).
2. Upload `index.html` to the root of the repository (`Add file` -> `Upload files` -> `Commit changes`).
3. If using a custom repository name (not `.github.io`), go to **Settings > Pages**, select `main` branch under **Build and deployment**, and click **Save**.
4. Your site will be live within 1–2 minutes!

## How to Update Content
- **New Publications:** Open `index.html` in GitHub (click the pencil icon ✏️ to edit directly in the browser), find `const PUBLICATIONS = [`, and add a new entry at the top of the list.
- **New Members or Presentations:** Edit the corresponding HTML section in `index.html` and click **Commit changes**.
